# 数览 DataStory

**上传数据，快速生成数据概览与交互式图表。**

## 项目简介

面向日常数据探索，将 CSV 或 Excel 数据整理为字段统计、质量概览和交互式可视化，帮助使用者更快了解数据结构与分布。

## 主要功能

- 展示字段类型、缺失情况、数值统计和数据预览。
- 根据数值、分类或日期字段生成图表，并支持筛选与字段切换。
- 可选接入兼容 OpenAI 的服务，对统计摘要生成中文解读。

**技术与实现**：Python、Streamlit；示例数据为虚构的电商订单汇总。

**使用边界**：字段识别是启发式判断，分析结果和 AI 解读需人工复核。上传的数据会到达应用所在服务器；启用 AI 解读时会发送经同意的统计摘要，使用前应确认数据和服务商的隐私要求。
