# 数览 DataStory

上传 CSV / Excel，自动查看数据质量、字段统计和交互图表；也可用自己的兼容 OpenAI 的 API 生成基于统计摘要的中文解读。面向数据分析岗位作品集，示例数据为虚构的电商订单汇总。

## 快速开始

需要 Python 3.10–3.12：

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

打开页面后选择内置示例，或上传 CSV、XLSX、XLS 文件（最大 10 MB）。支持 UTF-8 和 GB18030 CSV；Excel 读取第一张工作表。选择分类筛选后，所有指标及图表以筛选结果为准。

## 功能与分析规则

- 按数值、日期、分类/文本识别字段，展示前 100 行、缺失率及数值统计。
- 数值用直方图；分类按记录数或数值求和（最多显示前 20 类）；日期按天统计记录数或数值求和。可自行切换图表和字段。
- 日期识别要求大部分非空值具有日期分隔符并能解析；它是启发式规则，不保证所有数据均准确。数值型 ID 会被识别为数值，建议用户核实字段含义。
- 可选 AI 解读：提供 HTTPS 接口基础地址（如 `https://provider.example/v1`）、模型名和 API Key，勾选同意后发送界面显示的聚合摘要。不会默认发送原始数据行或分类取值，字段名本身仍可能敏感。Key 不写入项目文件，服务商可能按照自己的政策记录请求并收费。
- 此应用不提供登录和持久化报表；上传数据会到达应用运行的服务器。请不要将敏感数据用于不可信的公共演示。AI 地址默认仅允许 api.openai.com；部署者可通过环境变量 `ALLOWED_AI_HOSTS` 设置允许的域名（英文逗号分隔），切勿允许不可信域名。公开部署仍应配置出站网络策略，降低 DNS 重绑定等风险。

## 测试

```bash
python -m pytest -q
```

## 部署

可在支持 Streamlit 的托管服务中连接本仓库，入口设为 `app.py`；依赖从 `requirements.txt` 安装。

本项目聚焦自动化探索，不等同于业务结论或因果分析；首次数据类型判断、异常值和 AI 文字都应由分析者复核。后续可添加电商业务指标、字段类型手动修正与报表导出。
